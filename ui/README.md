# پوشه‌ی رابط گرافیکی (فاز ۴)

رابط گرافیکی Qt در فاز ۴ در این پوشه ساخته می‌شود.

- رابط فقط ورودی را می‌گیرد، منطق را از `core/` صدا می‌زند و نتیجه را نشان می‌دهد.
- منطق برنامه نباید به Qt وابسته باشد؛ به همین دلیل از فاز اول در `core/` نوشته می‌شود.
- هنگام شروع فاز ۴، یک `CMakeLists.txt` برای این پوشه بسازید و بخش `BUILD_UI` را در `CMakeLists.txt` اصلی فعال کنید.
